This directory contains the project-owned helper daemon used by release IPKs.

Do not commit Xray-core or sing-box runtime binaries here.

Runtime binaries must be installed on the TV by the user:

```text
/home/root/webos-xray-tun/bin/xray
/home/root/webos-xray-tun/bin/sing-box
```

Official sources:

```text
https://github.com/XTLS/Xray-core/releases
https://github.com/SagerNet/sing-box/releases
```
